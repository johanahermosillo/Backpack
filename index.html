    Import from Blackboard

    1. In Blackboard, open Calendar, then Calendar settings, then Share calendar.
    2. Copy the link and open it in your browser. It downloads a calendar file (.ics).
    3. Choose that file here. Importing again later updates the same items instead of adding copies.

    Tip: filter by one course, import it into that class's bucket, then repeat for the next course.
